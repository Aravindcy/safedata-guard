# Examples by domain

These use the synthetic datasets generated by `scripts/make_datasets.py` (run it
once to create `datasets/*.csv`). No real personal data is involved. Every
example plugs in your own `model` - any callable that takes a prompt string and
returns the model's text reply.

```python
import pandas as pd
import safedata as sd

def model(prompt):           # plug in any LLM (OpenAI, etc.)
    ...
```

The recommended entry point is `sd.safe_query` (SafePlan mode): the model returns
a JSON plan, safedata executes it locally, and you get a Data Safety Receipt.

## Banking - customer transactions

```python
df = pd.read_csv("datasets/banking_transactions.csv")
res = sd.safe_query(df, "What is the average balance by product?",
                    model=model, policy=sd.Policy.regulated())
print(res.answer)            # product-level aggregates, small groups suppressed
print(sd.format_receipt(res.receipt))
```

A raw-data request is refused: `sd.safe_query(df, "list every account number")`
returns `blocked=True` because raw row access is not a SafePlan operation.

## Protecting a whole conversation (SafeSession)

```python
s = sd.SafeSession(df, model=model, policy=sd.Policy.regulated(), budget=20)
s.ask("average balance in London")              # allowed
s.ask("average balance in London below 1000")   # blocked: differencing attack
s.ask("average balance in Manchester")          # allowed (disjoint population)
```

## Red-teaming your own setup (LeakScore)

```python
report = sd.leak_test(df, model=model, policy=sd.Policy.strict())
print(report.score, report.risk_level)
```
